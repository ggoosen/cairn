## How to sign

Small contributions — typos, documentation, an obvious one-line fix — are merged
without a CLA. For anything substantial, add a comment to your pull request
containing exactly:

```
I have read the Cairn CLA (CLA.md) and I hereby sign it.

Name:           <your full legal name>
GitHub username: <your username>
Email:          <email you want on record>
Date:           <YYYY-MM-DD>
```

That comment, made from your GitHub account, is your signature; the pull request
record is where it is retained. If you would rather not sign in public, say so on
the PR and the Maintainer will arrange a private channel.

If you are contributing on behalf of a company, a corporate CLA is needed
instead — open an issue titled `[cla]` and it will be sorted out before you
write any code.
